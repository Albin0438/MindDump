Hi there, Firefox is an open-source and nonprofit browser that lets its users customize and tweak the browser too deeply. Even the anonymous ‘Tor Browser’ is based on Firefox ESR code. Firefox already has most tools that are required for a normal user to browse the web efficiently. But still using some add-ons provides additional features and user control over the existing ones.

By using these add-ons I recommend, you can have a clean and fast web experience on Firefox.

uBlock Origin#

This addon doesn’t even need an introduction. It is widely used and very popular among privacy communities. It is not an ad blocker but a content-blocking browser extension developed by Raymond Hill.

Features#

  1. Powerful content blocking.

  2. Supports custom filter lists.

  3. Can remove specific elements in a website

  4. Cosmetic filtering

  5. Disables prefetching of resources and hyperlink auditing

  6. Optionally blocks remote fonts, disables JavaScript, and much more.

  7. Easy on CPU.

Even because of the effectiveness and adaptation of this extension, Google killed it using MV3 on Chrome and its based browsers. Just imagine then how powerful it is; even Google (an advertising company) is shocked by how this extension works.

Sponsorblock#

Used to skip sponsorship segments on YouTube videos. Works as simply as an ad blocker. The sponsor segments are submitted by SponsorBlock users. Based on the upvotes and downvotes, they decide if the segment is really a sponsor segment or not. Then it auto-skipped for every user.

  1. Customizable (you can decide if a sponsor segment is detected, if it should be auto-skipped, or if you should do it yourself when the skip button appears.)

  2. Various categories (sponsor, unpaid/self-promotion, end cards, interaction reminder, etc.)

  3. Segments are collected via community engagement. No corporation controls it.

  4. You can submit segments of your own if a video didn’t skip a sponsor segment.

AI block for YouTube#

Nowadays AI is everywhere. Even on YouTube there is too much AI-related stuff, like summaries, insights, and videos/shorts made using AI.

YouTube is a well-known and largely used platform by content creators. So switching to another platform is not possible most times. So this extension fixes the AI video problem in YouTube.

  1. Helps you to bypass the AI slop on YouTube by hiding AI-generated videos

  2. You can choose to hide it completely or show a warning.

  3. AI videos are submitted by users.

Disadvantages#

  1. currently only supports YouTube videos; there is still no support for Shorts.

Disable AI#

  1. Disables all AI features on all major search engines (Google, Bing, DuckDuckGo, Brave, etc.) just by installing this extension.

  2. By installing these extensions, you are telling search engines to not enable AI features, meaning you are indirectly supporting nature by preventing this AI processing from spending too much water and electricity.

*Google and Bing are not recommended to use. DuckDuckGo and Brave allow you to disable AI in settings. So this extension is actually not necessary but still makes the process easy for those who don’t want to do it manually.

Tampermonkey#

  1. This extension helps you to manage and use various userscripts.

  2. Can search for user scripts in GreasyFork, OpenUserJS, GitHub, etc.

only install trusted scripts.

StreetPass for Mastodon#

  1. An extension that helps you to find Mastodon users / profiles as you browse the web

  2. When StreetPass detects a Mastodon profile link, it is automatically added to the collection so later the user can browse through the collected profile links.

  3. Makes it easy to find and follow Mastodon profiles.

Chrome Mask#

Certain websites are specifically built for Chromium browsers (e.g., Google-owned websites). This website gives poor performance on Firefox-based browsers. In certain situations sites force you to be in a Chromium-based browser.

In such conditions, this extension becomes a great tool. It spoofs the Firefox browser to look like Chrome.

  1. This extensions isn’t enabled by default or can’t be enabled for all sites at once, which is a good thing.

  2. You can switch it on in specific sites where Firefox works poorly.

YouTube Tweaks#

Another extension like Improve for YouTube or Unhook, but with more control. This extension helps you to customize your YouTube experience to the next level.

Features#

  1. Change the number of videos per row/column.

  2. Customize video grid.

  3. Hide shorts, mixes, playlists, recommendations, etc.

  4. Change the homepage.

  5. Force the original audio track.

and more features.

Read Aloud#

Are you tired of reading long blog posts or news and not having enough time to read full posts? Eye strain is a daily problem? If yes, then this extension helps you to solve all these struggles.

  1. Just by clicking on a button, it reads an entire webpage for you.

  2. It uses text-to-speech technology.

Video Download Helper#

This extension detects videos on a website and allows you to download them directly.

  1. Works perfectly on major social media platforms and websites (YouTube, Instagram, X, etc.)

  2. no download limit

Downsides#

  1. Free users have limited download speed.



Hope you guys found all the extensions I mentioned useful. As I find more extensions, it will be updated to this post.

Thank you for reading.
